BAB 1 · PENDAHULUAN

1.1 Latar Belakang

Ujian Tengah Semester (UTS) mata kuliah Mobile Programming menuntut mahasiswa membangun aplikasi mobile secara utuh: mulai dari perancangan antarmuka, navigasi antar halaman, pengelolaan data, sampai pengujian. Aplikasi yang dibuat pada laporan ini bernama Rizal Docs, yaitu aplikasi repositori dan koleksi dokumen yang berjalan pada platform Android dengan framework Flutter.

Aplikasi ini menyimpan data pengguna dan data dokumen pada database lokal SQLite sehingga seluruh fitur dapat digunakan tanpa koneksi internet. Gambar profil, logo, dan sampul dokumen juga berasal dari aset lokal yang disertakan di dalam project, bukan diunduh dari internet.

1.2 Tema Aplikasi

Tema aplikasi ditentukan dari angka terakhir NIM. NIM 241011750067 berakhiran angka 7, sehingga tema yang dipilih adalah Aplikasi Repositori / Koleksi Dokumen. Tema tersebut diwujudkan dalam bentuk katalog dokumen: setiap dokumen memiliki judul, penulis, kategori, tahun, deskripsi, sampul, dan status favorit.

1.3 Tujuan

  • Membangun aplikasi Android berbasis Flutter sesuai tema repositori dokumen.
  • Menerapkan autentikasi (registrasi dan login) dengan validasi form dan SQLite.
  • Membangun dashboard dengan header, body yang dapat di-scroll, dan bottom navigation.
  • Menerapkan navigasi detail, aksi favorit dengan dialog konfirmasi, serta CRUD dokumen.
  • Mendokumentasikan setiap tahapan pembuatan antarmuka beserta source code aplikasi.

Tahap 2 — Validasi Form Login

Validasi dijalankan sebelum data dikirim ke database. Jika username atau password kosong, pesan kesalahan muncul tepat di bawah field masing-masing. Password juga divalidasi minimal enam karakter. Validator dipusatkan pada class AppValidators agar konsisten dipakai di halaman login dan registrasi.

Validator username dan password — lib/core/utils/validators.dart (baris 1–66)
/// Kumpulan validator form yang dipakai pada halaman login dan registrasi.
///
/// Dipisahkan dari widget agar mudah diuji dan dipakai ulang.
class AppValidators {
  const AppValidators._();

  static String? nama(String? value) {
    if (value == null || value.trim().isEmpty) {
      return 'Nama lengkap tidak boleh kosong';
    }
    if (value.trim().length < 3) {
      return 'Nama lengkap minimal 3 karakter';
    }
    return null;
  }

  static String? username(String? value) {
    if (value == null || value.trim().isEmpty) {
      return 'Username tidak boleh kosong';
    }
    return null;
  }

  static String? password(String? value) {
    if (value == null || value.isEmpty) {
      return 'Password tidak boleh kosong';
    }
    if (value.length < 6) {
      return 'Password minimal 6 karakter';
    }
    return null;
  }

  static String? konfirmasiPassword(String? value, String password) {
    if (value == null || value.isEmpty) {
      return 'Konfirmasi password tidak boleh kosong';
    }
    if (value != password) {
      return 'Konfirmasi password tidak sesuai';
    }
    return null;
  }

  /// Validator umum untuk field teks yang wajib diisi.
  static String? requiredField(String? value, String label) {
    if (value == null || value.trim().isEmpty) {
      return '$label tidak boleh kosong';
    }
    return null;
  }

  /// Validator tahun terbit dokumen (1900 - 2100).
  static String? tahun(String? value) {
    if (value == null || value.trim().isEmpty) {
      return 'Tahun tidak boleh kosong';
    }
    final int? year = int.tryParse(value.trim());
    if (year == null) {
      return 'Tahun harus berupa angka';
    }
    if (year < 1900 || year > 2100) {
      return 'Tahun harus di antara 1900 dan 2100';
    }
    return null;
  }
}

Method actionRegistrasi() memeriksa keunikan username, menyimpan data ke SQLite, lalu kembali ke halaman login dengan membawa username yang baru didaftarkan.

Method actionRegistrasi() — lib/features/auth/register_page.dart (baris 38–82)
  /// Memvalidasi form lalu menyimpan pengguna baru ke database SQLite.
  Future<void> actionRegistrasi() async {
    FocusScope.of(context).unfocus();

    if (!(_formKey.currentState?.validate() ?? false)) return;

    setState(() => _isLoading = true);

    try {
      final String username = _usernameController.text.trim().toLowerCase();
      final bool isTaken = await AuthRepository.instance.isUsernameTaken(
        username,
      );

      if (!mounted) return;

      if (isTaken) {
        await showAppDialog(
          context,
          title: 'Registrasi Gagal',
          message: 'Username sudah digunakan, silakan pilih username lain.',
        );
        return;
      }

      final User user = await AuthRepository.instance.register(
        nama: _namaController.text,
        username: username,
        password: _passwordController.text,
      );

      if (!mounted) return;
      showAppSnackBar(context, 'Registrasi berhasil, silakan login');
      Navigator.of(context).pop(user.username);
    } catch (error) {
      if (!mounted) return;
      showAppDialog(
        context,
        title: 'Terjadi Kesalahan',
        message: 'Tidak dapat menyimpan data: $error',
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

/// Menggunakan pola singleton agar hanya ada satu koneksi database selama
/// aplikasi berjalan.
class DatabaseHelper {
  DatabaseHelper._();

  static final DatabaseHelper instance = DatabaseHelper._();

  static Database? _database;

  Future<Database> get database async {
    return _database ??= await _openDatabase();
  }

  Future<Database> _openDatabase() async {
    final String databasePath = join(
      await getDatabasesPath(),
      AppConstants.databaseName,
    );

    return openDatabase(
      databasePath,
      version: AppConstants.databaseVersion,
      onConfigure: (Database db) async {
        await db.execute('PRAGMA foreign_keys = ON');
      },
      onCreate: _onCreate,
      onUpgrade: _onUpgrade,
    );
  }

  Future<void> _onCreate(Database db, int version) async {
    await _createUsersTable(db);
    await _createDocumentsTable(db);
    await _seedDocuments(db);
  }

  Future<void> _onUpgrade(Database db, int oldVersion, int newVersion) async {
    // Versi 2: menambahkan tabel dokumen beserta data awal dari aset lokal.
    if (oldVersion < 2) {
      await _createDocumentsTable(db);
      await _seedDocuments(db);
    }
  }

  Future<void> _createUsersTable(Database db) async {
    await db.execute('''
      CREATE TABLE ${AppConstants.usersTable} (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nama TEXT NOT NULL,
        username TEXT NOT NULL UNIQUE,
        password TEXT NOT NULL,
        created_at TEXT NOT NULL
      )
    ''');
  }

  Future<void> _createDocumentsTable(Database db) async {
    await db.execute('''
      CREATE TABLE ${AppConstants.documentsTable} (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        category TEXT NOT NULL,
        author TEXT NOT NULL,
        year INTEGER NOT NULL,
        description TEXT NOT NULL,
        image TEXT NOT NULL,
        is_favorite INTEGER NOT NULL DEFAULT 0,
        created_at TEXT NOT NULL,
        updated_at TEXT NOT NULL
      )
    ''');
  }

  Future<void> _seedDocuments(Database db) async {
    final int count =
        Sqflite.firstIntValue(
          await db.rawQuery(
            'SELECT COUNT(*) FROM ${AppConstants.documentsTable}',
          ),
        ) ??
        0;

    if (count > 0) return;

    final Batch batch = db.batch();
    for (final Document document in DocumentSeed.items) {
      batch.insert('documents', document.toMap()..remove('id'));
    }
    await batch.commit(noResult: true);
  }

  /// Menutup koneksi database. Dipakai oleh pengujian.
  Future<void> close() async {
    final Database? db = _database;
    if (db != null && db.isOpen) {
      await db.close();
    }
    _database = null;
  }

    }
    return null;

    }
    return null;
  }

      return '$label tidak boleh kosong';
    }
    return null;
  }

  ///
  /// Mengembalikan [User] jika cocok, atau `null` jika tidak ditemukan.
  Future<User?> login(String username, String password) async {
    final Database db = await DatabaseHelper.instance.database;
    final List<Map<String, Object?>> rows = await db.query(
      'users',
      where: 'username = ? AND password = ?',
      whereArgs: [username.trim().toLowerCase(), password],
      limit: 1,
    );

    if (rows.isEmpty) return null;
    return User.fromMap(rows.first);
  }

  /// Mengecek apakah username sudah dipakai.
  Future<bool> isUsernameTaken(String username) async {
    final Database db = await DatabaseHelper.instance.database;
    final List<Map<String, Object?>> rows = await db.query(
      'users',
      columns: ['id'],
      where: 'username = ?',
      whereArgs: [username.trim().toLowerCase()],
      limit: 1,
    );
    return rows.isNotEmpty;
  }

  /// Menyimpan pengguna baru dan mengembalikan data yang tersimpan.
  Future<User> register({
    required String nama,
    required String username,
    required String password,
  }) async {

  static final DocumentRepository instance = DocumentRepository._();

  Future<List<Document>> getAll() async {
    final Database db = await DatabaseHelper.instance.database;
    final List<Map<String, Object?>> rows = await db.query(
      'documents',
      orderBy: 'created_at DESC, id DESC',
    );
    return rows.map(Document.fromMap).toList();
  }

  Future<List<Document>> getFavorites() async {
    final Database db = await DatabaseHelper.instance.database;
    final List<Map<String, Object?>> rows = await db.query(
      'documents',
      where: 'is_favorite = ?',
      whereArgs: [1],
      orderBy: 'created_at DESC, id DESC',
    );
    return rows.map(Document.fromMap).toList();
  }

  Future<Document?> getById(int id) async {
    final Database db = await DatabaseHelper.instance.database;
    final List<Map<String, Object?>> rows = await db.query(
      'documents',
      where: 'id = ?',
      whereArgs: [id],
      limit: 1,
    );
    if (rows.isEmpty) return null;
    return Document.fromMap(rows.first);
  }

  Future<Document> create(Document document) async {
    final Database db = await DatabaseHelper.instance.database;
    final DateTime now = DateTime.now();
    final Document newDocument = document.copyWith(
      createdAt: now,
      updatedAt: now,
    );

    final int id = await db.insert(
      'documents',
      newDocument.toMap()..remove('id'),
    );
    return newDocument.copyWith(id: id);
  }

  Future<void> update(Document document) async {
    final int? id = document.id;
    if (id == null) {
      throw ArgumentError('Dokumen harus memiliki id untuk diperbarui.');
    }

      'documents',

      where: 'id = ?',

    );
  }

  group('AppValidators', () {
    test('nama wajib diisi dan minimal 3 karakter', () {
      expect(AppValidators.nama(null), 'Nama lengkap tidak boleh kosong');
      expect(AppValidators.nama('   '), 'Nama lengkap tidak boleh kosong');
      expect(AppValidators.nama('Ri'), 'Nama lengkap minimal 3 karakter');
      expect(AppValidators.nama('Rizal Suryawan'), isNull);
    });

    test('username wajib diisi', () {
      expect(AppValidators.username(''), 'Username tidak boleh kosong');
      expect(AppValidators.username('   '), 'Username tidak boleh kosong');
      expect(AppValidators.username('rizal'), isNull);
    });

    test('password wajib diisi dan minimal 6 karakter', () {
      expect(AppValidators.password(''), 'Password tidak boleh kosong');
      expect(AppValidators.password('12345'), 'Password minimal 6 karakter');
      expect(AppValidators.password('123456'), isNull);
    });

    test('konfirmasi password harus sama', () {
      expect(
        AppValidators.konfirmasiPassword('', 'rizal123'),
        'Konfirmasi password tidak boleh kosong',
      );
      expect(
        AppValidators.konfirmasiPassword('salah', 'rizal123'),
        'Konfirmasi password tidak sesuai',
      );
      expect(AppValidators.konfirmasiPassword('rizal123', 'rizal123'), isNull);
    });

    test('tahun harus berupa angka yang masuk akal', () {
      expect(AppValidators.tahun(''), 'Tahun tidak boleh kosong');
      expect(AppValidators.tahun('dua ribu'), 'Tahun harus berupa angka');
      expect(
        AppValidators.tahun('1800'),
        'Tahun harus di antara 1900 dan 2100',
      );
      expect(AppValidators.tahun('2025'), isNull);
    });

    test('requiredField memakai label pada pesan error', () {
      expect(
        AppValidators.requiredField('', 'Judul'),
        'Judul tidak boleh kosong',
      );
      expect(AppValidators.requiredField('Basis Data', 'Judul'), isNull);
    });
  });

import 'package:flutter_test/flutter_test.dart';

import 'package:rizal_apps/models/document.dart';

void main() {
  group('Document', () {
    final DateTime createdAt = DateTime(2024, 6, 18, 10, 30);

    final Document document = Document(
      id: 1,
      title: 'Basis Data Relasional',
      category: 'Teknologi',
      author: 'Gusmayeni',
      year: 2022,
      description: 'Buku tentang basis data relasional.',
      image: 'assets/images/covers/cover_03.png',
      isFavorite: true,
      createdAt: createdAt,
      updatedAt: createdAt,
    );

    test('toMap dan fromMap menghasilkan data yang sama', () {
      final Map<String, Object?> map = document.toMap();
      final Document result = Document.fromMap(map);

      expect(map['is_favorite'], 1);
      expect(result.id, document.id);
      expect(result.title, document.title);
      expect(result.category, document.category);
      expect(result.author, document.author);
      expect(result.year, document.year);
      expect(result.description, document.description);
      expect(result.image, document.image);
      expect(result.isFavorite, isTrue);
      expect(result.createdAt, createdAt);
    });

    test('fromMap membaca is_favorite 0 sebagai false', () {
      final Map<String, Object?> map = document.toMap()..['is_favorite'] = 0;

      expect(Document.fromMap(map).isFavorite, isFalse);
    });

    test('copyWith hanya mengubah field yang diberikan', () {
      final Document updated = document.copyWith(
        title: 'Judul Baru',
        isFavorite: false,
      );

      expect(updated.title, 'Judul Baru');
      expect(updated.isFavorite, isFalse);
      expect(updated.author, document.author);
      expect(updated.createdAt, document.createdAt);
    });
  });
}

/// Pengujian end-to-end alur utama aplikasi:
/// registrasi -> login -> detail & favorit -> tab favorit -> tambah dokumen
/// -> ubah dokumen -> hapus dokumen.
void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  /// Menjalankan aksi tombol FilledButton secara langsung.
  ///
  /// Dipakai untuk tombol yang berada di dalam area scroll agar pengujian tidak
  /// bergantung pada posisi scroll maupun hit-testing pada perangkat.
  Future<void> pressFilledButton(WidgetTester tester, String label) async {
    final Finder finder = find.widgetWithText(FilledButton, label);
    final FilledButton button = tester.widget<FilledButton>(finder);
    expect(button.onPressed, isNotNull);
    button.onPressed!();
    await tester.pumpAndSettle();
  }

  testWidgets('alur registrasi, login, favorit, dan CRUD dokumen', (
    WidgetTester tester,
  ) async {
    final String unique = DateTime.now().millisecondsSinceEpoch.toString();
    final String username = 'rizal$unique';

    await app.main();
    await tester.pump(const Duration(seconds: 2));
    await tester.pumpAndSettle();

    // --- Registrasi ---------------------------------------------------------
    await tester.tap(find.text('Registrasi Akun Baru'));
    await tester.pumpAndSettle();

    final Finder registerFields = find.byType(TextFormField);
    await tester.enterText(registerFields.at(0), 'Rizal Suryawan');
    await tester.enterText(registerFields.at(1), username);
    await tester.enterText(registerFields.at(2), 'rizal123');
    await tester.enterText(registerFields.at(3), 'rizal123');
    await pressFilledButton(tester, 'Daftar');

    // Kembali ke halaman login setelah registrasi berhasil.
    expect(find.text('Masuk ke Akun'), findsOneWidget);

    // --- Login --------------------------------------------------------------
    final Finder loginFields = find.byType(TextFormField);
    await tester.enterText(loginFields.at(0), username);
    await tester.enterText(loginFields.at(1), 'rizal123');
    await tester.tap(find.widgetWithText(FilledButton, 'Masuk'));
    await tester.pump();
    await tester.pump(const Duration(milliseconds: 600));

    expect(find.text('Login berhasil'), findsOneWidget);

    await tester.pumpAndSettle();

    // --- Dashboard ----------------------------------------------------------
    expect(find.text('Koleksi Dokumen'), findsOneWidget);
    expect(find.text('Halo, Rizal Suryawan'), findsOneWidget);

    // --- Detail & favorit ---------------------------------------------------
    await tester.tap(find.byType(DocumentCard).first);
    await tester.pumpAndSettle();

    expect(find.text('Deskripsi'), findsOneWidget);

    await tester.tap(find.text('Tambah ke Favorit'));
    await tester.pumpAndSettle();

    expect(find.byType(AlertDialog), findsOneWidget);
    await tester.tap(
      find.descendant(of: find.byType(AlertDialog), matching: find.text('Ya')),
    );
    await tester.pump();
    await tester.pump(const Duration(milliseconds: 600));

    expect(
      find.text('Dokumen berhasil ditambahkan ke favorit'),
      findsOneWidget,
    );
    expect(find.text('Hapus dari Favorit'), findsOneWidget);

    await tester.pageBack();
    await tester.pumpAndSettle();

    // --- Tab favorit --------------------------------------------------------
    await tester.tap(
      find.descendant(
        of: find.byType(BottomNavigationBar),
        matching: find.byIcon(Icons.favorite_border_rounded),
      ),
    );
    await tester.pumpAndSettle();

    expect(find.text('Favorit Saya'), findsOneWidget);
    expect(find.byType(DocumentCard), findsWidgets);

    // --- Menu pengaturan: create -------------------------------------------
    await tester.tap(
      find.descendant(
        of: find.byType(BottomNavigationBar),
        matching: find.byIcon(Icons.settings_outlined),
      ),
    );
    await tester.pumpAndSettle();

    expect(find.text('Daftar Dokumen'), findsOneWidget);

    await tester.pumpAndSettle();
